# Setup checklist: <app name> for <client>

The 30-minute runbook from Membrain `docs/apps.md`. Tick each box as it is done; note anything skipped under Follow-ups.

## Before the call (must already exist)
- [ ] A brain kind for this type of business, with folders, rules and SITEMAP rows
- [ ] Its question list (coverage checklist) with required items marked
- [ ] This app's `APP.md` with sensible defaults the client only confirms or edits
- [ ] `DATA-STORE.md` with the proposed rung (usually rung 1)
- [ ] Optional: research pre-fill from public information, each fact with source and confidence
- [ ] Who will answer (owner, or someone on the owner's behalf) and who can create or share folders on the client's side

## 0-5 min: create and share the brain
- [ ] Brain created from the brain kind and lint passes
- [ ] Client editors added; intake chat link shared

## 5-20 min: collect the workflow
- [ ] Researched facts confirmed or corrected
- [ ] Every required question covered; unknowns listed as open questions
- [ ] Answers from someone other than the owner marked "owner to confirm"

## 20-25 min: link document storage
- [ ] Store created from the spec (rung 1: one tab per entity, folders from file_storage)
- [ ] Shared with named people only; nothing public
- [ ] `DATA-STORE.md` filled in and committed; no secrets in the brain

## 25-30 min: test run
- [ ] One end-to-end case on test data, checked against each rule in `APP.md`
- [ ] Result logged; profile status set to in_review

## After the call
- [ ] Approver reviewed and set approved
- [ ] Setup built from the approved spec and recorded what it set
- [ ] Brain linted; one log entry written
