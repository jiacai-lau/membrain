# App starter (scaffolding only)

This folder is a blank app scaffold from Membrain. It contains no app code. Read Membrain `docs/apps.md` first.

To start an app:

1. Copy this folder to `apps/<name>/` (lowercase-dashes, e.g. `apps/tour-booking/`). Keep `_starter` as it is; upgrades may refresh it.
2. Fill in `APP.md`: replace every `<...>` prompt with real values from this brain's files and the owner's answers. Leave unknowns under `## Open questions`, never guess.
3. Fill in `DATA-STORE.md` with the chosen rung and where the live data is. No credentials, ever.
4. Work through `SETUP-CHECKLIST.md` (the 30-minute runbook) when setting the app up with a client.
5. Add a SITEMAP row for `apps/<name>/` and get the owner's OK before anything is built, a data store is created or data is sent anywhere.

| File | What it is |
|---|---|
| `APP.md` | The app spec: frontmatter plus plain-language sections |
| `DATA-STORE.md` | Pointer to the live data store: rung, location, owner, backups |
| `SETUP-CHECKLIST.md` | Time-boxed setup runbook as tick boxes |
