# Inbox: proposed lines

A review queue, not a task board. Agents and automatic capture propose here; the owner decides.
Decision is for the exact text. If the text changes, it needs a new decision.

```
- [ ] <proposed line> · YYYY-MM-DD · proposed-by @who · target:<file> · privacy:<SHAREABLE_REVIEWED|PRIVACY_REVIEW_NEEDED>
```
Owner marks `[x] promote`, `[x] keep-out` or `[x] needs-redaction`, then moves promoted lines to the target file.
