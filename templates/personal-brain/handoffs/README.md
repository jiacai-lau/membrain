# Handoffs

Longer notes, returns and replies. One file per version; never overwrite or delete.

Name: `<TYPE>-<FROM>[-to-<TO>]_<TASK>_<topic>_YYYY-MM-DD_v<N>.md`
TYPE: NOTE, RETURN, QUERY, REPLY, REQUEST, CORRECTION. Superseded files may be renamed `SUPERSEDED-by-v<N>_<name>`.

Each handoff starts with: Owner, Updated at (with time zone), Status, TLDR, Next action and who does it.
Notification: NOT_SENT unless a human sent it.
