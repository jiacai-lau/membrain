# Playbook: known fixes

One line per fix. Leave the chat where it happened; link it with `src:`.

## How to add a line

```
- <symptom> → <fix> · <client or context> · YYYY-MM-DD · @you · verified|unverified · src:<ticket id or link>
```

Search first. To retire a line, append ` · SUPERSEDED YYYY-MM-DD: <reason>`; never delete or rewrite it.
