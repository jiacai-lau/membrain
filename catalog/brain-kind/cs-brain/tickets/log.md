# Tickets

Client issues live on the team's issue log; a code fix also goes on the engineering backlog. This file keeps one line per ticket so agents can find it.

## How to file
1. Add one row on the issue log: date, client, issue, resolution, status Open, Closed or Ongoing.
2. If the case needs a code change, search the backlog first. If a ticket already covers it, link that one. Do not open a second ticket.
3. Ask the brain owner whether it is a bug or a feature before calling it a bug.
4. Create a backlog ticket only when the owner asks. The owner assigns the engineer.
5. Add one line below.

## Filed

```
- <ticket id> · <title> · <client> · YYYY-MM-DD · @you · Open|Closed|Ongoing
```
