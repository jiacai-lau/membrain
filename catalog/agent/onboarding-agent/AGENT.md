# Onboarding agent — concept (IDEA)

Status: **idea**. No code.

## Job
1. Watch (or be pointed at) one client's upload folder from `client-onboarding-portal`.
2. Draft import rows for customers, items and prices as reviewable markdown or CSV. Cite the source file and row for every draft line.
3. Hand the draft to an admin. Do not call any write tool.
4. After an explicit yes naming the rows, call the write tool only for those rows. Read back. Log.
5. Stop and ask on any price, personal contact or credential found in an upload — those belong in the personal brain, not the draft.

## Non-goals
- No silent writes.
- No inventing codes or prices missing from the upload.
