# onboarding-agent (agent)

**Status:** idea · **Version:** 0.1.0 · **Who it's for:** the admin who reviews a new client's imports.

## Purpose
**Idea only: no code.** A hire that reads a client's uploaded files, drafts customer, item and price imports for review, and never writes without an admin's yes naming the rows.

## Depends on
Nothing. `client-onboarding-portal` depends on it; it can also work from any upload folder.

## Install
Status **idea**: `catalog.py install onboarding-agent --docs` copies `AGENT.md` into your personal brain. Register nothing in your agent platform until it is built and tested.
