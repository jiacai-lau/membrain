# client-onboarding-portal (app)

**Status:** idea · **Version:** 0.1.0 · **Who it's for:** a team that onboards each client by collecting files and turning them into imports.

## Purpose
**Idea only: no code.** A small portal: the client answers intake questions in a chat and uploads files into a fixed folder structure; `onboarding-agent` drafts the imports; an admin approves before anything is written to the client's system.

## Depends on
`onboarding-agent` (idea, same catalog).
